# Voice prompts

BTS Telephony uses a Kokoro-compatible text-to-speech service to generate voice
prompts. Kokoro may run on the same machine as BTS Telephony or on another
machine reachable over the network. `BTS_KOKORO_URL` selects the HTTP speech
endpoint. See [Setting up BTS Telephony](telephony-setup.md) for beginner local
and remote installation instructions.

Telephony uses the British `bf_emma` voice and generates and caches prompts
automatically on first use; cached prompts work without Kokoro afterwards.

Telephony accepts these environment variables:

```env
BTS_KOKORO_URL=http://127.0.0.1:8880/v1/audio/speech
BTS_KOKORO_VOICE=bf_emma
BTS_KOKORO_MODEL=kokoro
BTS_KOKORO_MODEL_VERSION=0.6.0
BTS_KOKORO_SPEED=1.05
BTS_VOICE_LANGUAGE=en
```

The welcome message and each semantic addon menu option are rendered separately.
Addon manifests provide labels and speaking style rather than Asterisk media
filenames; Telephony generates speech such as “Press seven for the weather”
from the current digit and sends each prompt through the configured BTS voice.
Runtime speech is converted to 8 kHz mono PCM and content-addressed by its exact
text, language, voice, model version, speed and output format. The canonical
cache is `/var/cache/bts/voice`; Asterisk-visible files are published only in
the BTS-owned `bts-generated` sound namespace. A failed dynamic prompt is logged
with its text, plays Asterisk's emergency error tone, and abandons that incomplete
queue without terminating Telephony.

Both directories are owned by the Telephony runtime. Ordinary removal preserves
the content-addressed cache for a later reinstall; `bts-install remove telephony
--purge` and purging uninstall remove only these exact BTS-owned directories.
Upgrade cleanup removes only the exact legacy prompt filenames previously
generated by BTS under `sounds/en/bts`; unrelated operator-provided Asterisk
audio is never scanned or deleted.

Session configuration prompts and dynamic terminal and group names use the same
BTS voice. Timing and interruption behaviour must be checked manually with the
deployed Asterisk and telephone hardware.
